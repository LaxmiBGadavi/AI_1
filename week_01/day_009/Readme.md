# Day 009 – Python Fundamentals for Agentic AI

## Concepts Learned

### 1. Lists
- Creating lists
- Accessing list elements
- Positive and negative indexing
- Adding and removing elements
- List slicing

### 2. Dictionaries
- Creating dictionaries
- Key-value pairs
- Accessing dictionary values
- Dictionary methods
- Iterating through dictionaries

### 3. List Comprehensions
- Creating lists using comprehensions
- Filtering elements
- Applying conditions
- Generating transformed lists

### 4. Dictionary Comprehensions
- Creating dictionaries using comprehensions
- Generating key-value pairs
- Filtering dictionary elements

### 5. F-Strings
- Formatting strings
- Inserting variables into strings
- Creating readable dynamic output

### 6. Slicing
- Extracting elements using indexes
- Selecting specific ranges
- Reverse slicing using `[::-1]`

## Practical Exercises

1. Even Number Finder – Filter even numbers using list comprehension.
2. Word Length Calculator – Calculate word lengths using dictionary comprehension.
3. Student Marks Analyzer – Filter student marks using dictionary comprehension and display results using f-strings.

## Connection to Agentic AI

These Python concepts are useful for:
- Managing structured data.
- Processing agent inputs and outputs.
- Handling tool responses.
- Filtering and transforming information.
- Managing conversation data.

## Learning Outcome

Learned Python lists, dictionaries, comprehensions, f-strings and slicing, which are important foundations for building AI agents and automation applications.
