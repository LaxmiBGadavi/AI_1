## Important Commands

**Check Python Version**
```bash
python --version
```

**Check uv Version**
```bash
uv --version
```

**Create Virtual Environment**
```bash
uv venv
```

**Activate Virtual Environment (Windows)**
```bash
.venv\Scripts\activate
```

**Install Packages**
```bash
uv pip install package_name
```

**Deactivate Virtual Environment**
```bash
deactivate
```
